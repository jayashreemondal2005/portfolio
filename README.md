# Jayashree Mondal — Portfolio

**Live Site:** [https://jayashreemondal-portfolio.netlify.app/](https://jayashreemondal-portfolio.netlify.app/)

My personal portfolio website. I'm a B.Tech IT student (BCET, 2023–2027) interested in AI/ML,
web and full-stack development. The site has my background, skills, projects, certificates and a
contact form.

Built with plain **HTML, CSS and JavaScript** — no frameworks, no build step.

## What's inside

- **Projects** — Fresnel (accessibility & performance checker), Finance Story, Amazebot,
  Face Mask Detection and an Online Examination System, with links to live demos and code
- **Certificates** — filterable grid with a built-in viewer (keyboard and swipe navigation)
- **Journey** — timeline of my internship, courses and certifications
- **Contact form** — sends messages to my inbox through FormSubmit, checks that the email
  domain is real before sending, and falls back to the visitor's mail app if the service is down
- Light / dark theme (remembered between visits), animated canvas background, scroll progress bar,
  live clock and a short guided tour for first-time visitors
- Responsive layout and `prefers-reduced-motion` support

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5500
```

then visit http://localhost:5500

Featured Projects

Fresnel — Website Accessibility & Performance Checker

Paste a GitHub repo URL and Fresnel audits the source for Performance, Accessibility, Best Practices, SEO and common security issues. Every finding comes with a ready-to-apply Git diff, a downloadable .patch file and a one-line PR command. It can also read a Lighthouse JSON report and trace failing audits back to the code.

Finance Story — Managed Agent

Turns a Google Drive folder, Google Sheet, Excel workbook or CSV ledger into an animated, chapter-by-chapter story of where the money went — plus a day-by-day explorer and a plain-English question box powered by Gemini. The data pipeline (parse → clean → categorise → reconcile) is covered by Vitest tests.

TypeScriptVitePixiJSGSAPGemini APIVitest

Amazebot — Multi-Agent Chatbot

A Streamlit chatbot that routes each question to a Research agent or a Summarizer agent. It corrects spelling, detects the language and translates replies, lets you edit earlier messages, share chats and export them to PDF — and drops into an offline demo mode when no Gemini key is set.

PythonStreamlitGemini APINLPMulti-Agent

Face Mask Detection

Real-time mask / no-mask detection on a live webcam feed. Faces are found with an OpenCV Haar cascade and classified by a MobileNetV2 model fine-tuned with TensorFlow/Keras. The repo includes the training script, the trained model and the accuracy/loss plot.

PythonOpenCVTensorFlowMobileNetV2Computer Vision

Online Examination System

A multi-page exam portal with separate student and admin flows. Admins set question papers and schedule exams; students take timed tests with answers saved as they go, a question palette to jump around, then check results and download a grade card as PDF. Runs fully in the browser using localStorage.
